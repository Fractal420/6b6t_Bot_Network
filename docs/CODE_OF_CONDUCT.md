# Code of Conduct

We want 6bBotAPI to be a welcoming and constructive project for everyone.

## Expected behavior

- Treat contributors and maintainers with respect.
- Criticize code and ideas constructively, not people.
- Welcome different experience levels and viewpoints.
- Respect others' privacy and boundaries.
- Accept feedback professionally.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing private information without consent.
- Deliberately disrupting discussions or targeting contributors.
- Any other conduct that makes participation hostile or unsafe.

## Scope

This code applies to project spaces, including issues, pull requests, discussions, and other spaces where someone represents the project.

## Enforcement

Report misconduct privately to the project maintainers through an available contact.

Maintainers will review reports fairly and may remove content, issue warnings, restrict participation, or take other appropriate action.

Participation in 6bBotAPI's community means automatically agreeing to follow this code.
